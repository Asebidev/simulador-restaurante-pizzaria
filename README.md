# Simulador-Restaurante

Simulador de Eventos Discretos (DES) de um restaurante em **TypeScript**, desenvolvido para a disciplina de Programação Orientada a Objetos (ADS > Prof. Iallen Gábio).

O sistema simula o fluxo de clientes, garçons e estações da cozinha para medir tempos de espera, satisfação e identificar gargalos na operação.

## Como Executar

```bash
# Instalar dependências
npm install

# Rodar a simulação
npm start
```

Os parâmetros da simulação (mesas, garçons, cozinha e cardápio) podem ser ajustados diretamente no arquivo `configuracao.json`.
